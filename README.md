# 🔐 Password Strength Checker

> 🚀 A simple yet powerful Python tool to analyze and rate password strength.

---

## ✨ Features

✅ Checks password length
✅ Detects uppercase & lowercase letters
✅ Identifies numbers
✅ Detects special characters
✅ Provides strength rating (Weak / Medium / Strong)

---

## 🖥️ Demo

```bash
Enter your password: Test@123
Password Strength: Very Strong 🔥
```

---

## 📊 How It Works

The tool evaluates your password based on:

| Criteria           | Description          |
| ------------------ | -------------------- |
| Length             | Minimum 8 characters |
| Uppercase Letters  | A–Z                  |
| Lowercase Letters  | a–z                  |
| Numbers            | 0–9                  |
| Special Characters | !@#$%^&* etc.        |
